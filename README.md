# Living Villages — импорт исходников

Репозиторий подготовлен для импорта мода из ZIP-архива.

## Как добавить исходники

1. Скачайте подготовленный архив Living Villages 0.15.0 из текущего чата.
2. В корне этого репозитория выберите **Add file → Upload files** и загрузите ZIP-файл целиком.
3. Зафиксируйте загрузку в ветке `main`.

GitHub Actions автоматически распакует архив, перенесёт исходники в корень репозитория, добавит проверки Java-синтаксиса и регрессионные тесты, затем создаст коммит с исходниками и запустит сборку Gradle.

**Важно:** пока ZIP не загружен в репозиторий, исходный код мода ещё не находится в GitHub. Полная компиляция Minecraft/NeoForge не подтверждена локальными статическими тестами; результат сборки будет виден в разделе **Actions**.
