## Исправлено во время стабилизации

- Исправлена ошибка типизации компаратора при выборе самого голодного взрослого жителя.
- Обработчик клиентской панели старосты переведён на `IPayloadContext.enqueueWork`, вместо несуществующего в выбранной NeoForge версии `DistExecutor`.
- Добавлен недостающий импорт `Items` и удалён повторно объявленный `isStorageBlock` в системе лесозаготовки.
- Исправлены обращения к несуществующему `accessibleCount` в системе ремесленника: используется реальный `availableCount`.
- Сравнения предметов рецепта исправлены с `ItemStack.is(...)` на сравнение объектов `Item`.
- Структура GitHub: Java-код, переводы, NeoForge metadata, тесты и Gradle wrapper перемещены в соответствующие каталоги; `gradlew` отмечен исполняемым.
- Регрессионный тест и валидатор синхронизированы с исправленным компаратором.

## Пока не проверено

- Запуск и интерфейс клиента через `./gradlew runClient`.
- Открытие и использование панели старосты в реальном игровом клиенте.
- Реальное поведение ИИ в сохранённом мире: маршруты, рубка дерева, перенос предметов, строительство дома, ферма, крафт, защита и естественное размножение.
- `runClient` и открытие/использование панели старосты в реальном игровом клиенте.
- Реальный сценарий с двумя соседними деревнями: независимые старосты, население, назначения ролей и заказы.
- Полная изоляция физических сундуков, кроватей и рабочих блоков между соседними деревнями.
- Мультиплеер, смерть работника посреди задачи и восстановление проекта после перезапуска мира.
- Нагрузочное поведение при больших поселениях.

Успешный `build` подтверждает компиляцию. Smoke-test подтверждает старт dedicated server. Ни одна из этих проверок сама по себе не доказывает корректность всех игровых сценариев.

## Как воспроизвести

```sh
python3 tools/validate_project.py
java tools/JavaSyntaxCheck.java src/main/java
for test_file in tools/test_*.py; do python3 "$test_file"; done
sh -n gradlew BUILD_LOCAL.sh
./gradlew build
./gradlew runServer
```

Для ручного тестирования запускай отдельный тестовый мир и не используй непроверенную сборку в основном сохранении.
